# Documentation des acquis  Elan Fitness

## 1. Présentation du projet

Élan Fitness est un site web de salle de sport réalisé en HTML et CSS. L'objectif du projet était de passer d'un site one-page à un site multipage pour faciliter la navigation et mieux organiser le contenu.

## 2. Technologies utilisees

- **HTML5 :** pour organiser le contenu des pages.
- **CSS3 :** pour travailler le design, les couleurs, les espacements et la mise en page.
- **Flexbox :** pour organiser et aligner les éléments.
- **Media Queries :** pour adapter le site aux différentes tailles d'écran.
- **Animations CSS :** pour ajouter quelques effets légers au site.
- **Git et GitHub :** pour gérer les modifications et partager le code.
- **GitHub Pages :** pour héberger le site en ligne.

## 3. Travail réalisé

Le projet contient plusieurs pages, notamment Accueil, Programmes, À propos et Contact.

Ma principale contribution a été la réalisation de la page **Contact**, avec son formulaire et sa mise en page en CSS.

Pour les autres pages, j'ai principalement travaillé sur le responsive afin d'améliorer leur affichage sur les ordinateurs, les tablettes et les téléphones. J'ai également ajouté quelques animations légères pour améliorer la présentation du site.

## 4. Ce que j'ai appris

Ce projet m'a permis de pratiquer HTML et CSS sur un site concret. J'ai appris à organiser les éléments avec Flexbox, à adapter la mise en page avec les Media Queries et à corriger certains problèmes d'affichage sur différentes tailles d'écran.

J'ai aussi amélioré ma façon de travailler avec Git et GitHub, notamment pour enregistrer mes modifications et publier le projet en ligne.
